📥 Import Members from Excel / CSV

Upload an Excel (.xlsx) or CSV file with columns: Name, Password (header row required). Username is optional — auto-generated from name if not included.

Excel columns: Name | Password (optional: Username)

CSV format also accepted:
name,password
Jane Smith,pass123

(or with optional username column:)
username,name,password
jsmith,Jane Smith,pass123

🗑 Delete ALL Campaigns

This will permanently delete ALL campaigns, their member assignments, and all associated checklist data.

⚠️ This action cannot be undone. All campaign records and checklist progress will be lost.

🗑 Delete ALL Checklists

This will permanently delete ALL checklist progress for every member across every campaign.

⚠️ This action cannot be undone. All D-5 and D-1 statuses and notes will be lost.
